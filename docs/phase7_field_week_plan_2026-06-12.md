# Phase 7 — Structured Field Week (Test Plan, 2026-06-12)

Purpose: one week of REAL use, structured to sweep every subsystem and surface
weak points. Rule of the week: each day has a theme + deliberate probes, but
AT LEAST HALF of each day is genuine work — probes find the weaknesses we
designed against; honest use finds the ones we never imagined.

## The logging discipline (this IS the deliverable)

Keep one running note (Telegram saved messages, or a `phase7_log.md`). For
every disappointment, one line, immediately, with a tag:

```
[TAG] what I asked → what happened → what I expected
```

Tags: `WRONG-SHAPE` (output exists but wrong structure) · `GENERIC` (correct
but template-feeling) · `MIS-ROUTE` (wrong lane/skill/artifact type) ·
`FORGOT` (lost context I just gave) · `SLOW` (latency I felt) · `REFUSED`
(wrongly blocked/over-confirmed) · `OVERCONFIDENT` (asserted something wrong
or unverified) · `NO-PACK` (domain question with no knowledge pack) ·
`AVOIDED` (the silent killer: something I chose NOT to ask Maya because I
assumed she'd fail — log what and why).

End of each day: 2 minutes, count tags, note the day's worst moment and best
moment. That's it.

## Day 1 — Daily driver (chat, memory, reminders, routing)

Theme: use Maya for everything small, all day. The friction inventory.

Real use: morning brief, reminders, quick questions, notes, translations,
calculations — whatever the day actually brings.

Probes:
1. `remember that my nephew's birthday is July 3` → later: `when is my nephew's birthday?` → next day: ask again (cross-day recall).
2. Ask three questions in a row on ONE topic where each depends on the last ("what's EPF?", "what's the dividend rate?", "so how much on 50k?") → log every `FORGOT` (window is OFF — these failures are the evidence that decides enabling it; we WANT them counted, not avoided).
3. `forget my nephew's birthday` → ask again → must not resurrect. Then check the weekly memory flow doesn't bring it back (the Phase 3 leftover item).
4. If you have >80 saved memories: recall something OLD (pre-cliff regression check — still unchecked from Phase 3).
5. One voice request on the iMac; one photo to Telegram; one /command — all three intake paths in one day.
6. `what did we talk about this morning?` → tests session search honestly.

## Day 2 — Documents day

Theme: files should feel collaborative, not fire-and-forget.

Probes:
1. Create one Word document, one Excel workbook, and one PowerPoint deck from
   real topics.
2. During voice creation, steer the active task naturally: "Actually, it's for
   my ED", "also include assumptions", or "change it to an executive version".
3. After the file opens, manually edit one line, then ask Maya to add or revise
   something. Expected: Maya preserves the manual edit or creates a v2 instead
   of overwriting.
4. Log prompt, steer phrase, action taken (`merged`, `edited in place`, `v2`),
   file path, and pass/fail.
